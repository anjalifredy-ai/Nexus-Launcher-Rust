# Nexus Launcher (Rust)

```bash
cargo run -p nexus-start -- --version 26.3 --profile performance --seconds 1
```

## Live

- Unlimited FPS loop
- World: 9 chunks
- **Mesh: ~23040 tris** (tops + 4 sides)
- Software draw from **world heights**
- preview.ppm
